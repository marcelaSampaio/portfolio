Open source library TypeScript · zero dependencies

polygon-offset

Offsetting a polygon so that every point of the result is actually at the distance you asked for. The intuitive method — push each vertex along its angle bisector — puts the corner at d / sin(θ/2) instead of d; on a star offset by 40 the worst point lands 121.8 units out. It still looks like an offset, which is the problem.

The library ships maxDeviation as part of its public API, because a picture cannot tell you an offset is correct. It also ships the naive method, so the error is measurable rather than asserted. 57 tests, the core of them one property asserted across five shapes: every returned point is at the requested distance, to 1e-6.

Open source Three.js · WebGL

Parametric product configurator

A 3D configurator with no model file. Most load a finished mesh and swap its materials, which demos well and says nothing about whether the thing can be made. Here the parameters are dimensions in millimetres: changing the gusset depth doesn't select a variant, it rebuilds the geometry — and moves the gusset on the 2D cutting layout by the same millimetres.

The cutting line is a polygon offset of the sewing line, and the page measures every point of it back to the sewing line: 0.00 mm. Three.js vendored rather than pulled from a CDN, so it has no external runtime dependency.

Open source Packing under constraints

Nesting playground

Nesting looks like bin packing until the material starts making rules: the roll is a fixed width and unbounded length, pieces must run along the grain so most get two rotations rather than four, and everything needs a gap. Each constraint is a control here rather than a paragraph, so its cost is visible in metres — dropping the grain lock on the default four-garment marker takes it from 2.54 m to 2.44 m.

Bottom-left fill with a skyline accelerator on a raster grid, run across four orderings because greedy placement is order-dependent and none wins on every mix. The grid resolution is a control too, so you can watch efficiency fail to improve monotonically as it gets finer — which is the greedy showing through, and the reason production nesters run search on top.

Open source library TypeScript · React · Angular

looks-glassy

Refractive glass components for React and Angular, built on physics-based SVG displacement maps rather than a backdrop blur pretending to be glass. A framework-agnostic core generates the displacement map and builds the SVG filter; thin React and Angular packages wrap it.

Refractive index, glass thickness, bezel width, surface profile, specular angle and saturation are all parameters, so the effect is tuned like an optical material instead of dialled in by eye — with graceful fallbacks where the filter chain isn't supported.

Architecture case Rails · Sidekiq · PostgreSQL

LLM outreach pipeline

A six-stage pipeline where the interesting part is everything around the model call. Daily and per-record spend ceilings are checked before the request rather than after. A circuit breaker opens on provider failure and the workers re-queue with a delay instead of burning their retry budget — and it only counts API errors, so a bug in my own code raises through instead of hiding behind an open circuit.

Sources are pluggable behind one interface, deduplication leans on a unique index rather than check-then-insert so concurrent workers can't both win, and nothing reaches a recipient without passing a human approval gate. Each stage sits behind its own feature flag, switchable without a deploy.
